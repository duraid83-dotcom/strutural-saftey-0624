About / Assumptions

This is an educational structural engineering calculator for a university project. It is not a design code checker and must not be used for real construction decisions.

Results depend entirely on the values you type and on the assumptions of each case:

  • Units are converted to SI internally (N, m, Pa) before any formula is applied.
  • SAFE means the computed stress (or load) does not exceed the allowable value you entered (factor of safety ≥ 1). If you enter a yield stress as “allowable”, FoS is against yield, not against a code allowable.
  • Axial and tension cases use σ = P / A. Buckling is not included unless you choose Compression Member.
  • Compression uses both crushing (σ_allow × A) and Euler buckling P_cr = π²EI / (KL)². Euler assumes a perfectly straight, elastic column.
  • Beam cases are simply supported, Euler–Bernoulli (no shear deflection), with either a midspan point load or a full-span UDL.
  • Self-weight, connections, residual stresses, and second-order effects are not modelled unless you include them in the loads.
